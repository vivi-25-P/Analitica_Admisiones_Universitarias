# Guía de hojas de BaseUnificada Entregable

La tabla para el análisis es BaseUnificada. Las otras hojas explican, controlan o resumen sus mismos registros. No se suman como fuentes nuevas.

| Hoja | Filas | Uso |
| :--- | ---: | :--- |
| BaseUnificada | 5500 | Tabla principal para analizar los registros integrados. Contiene 18 columnas. |
| Diccionario_Datos | 18 | Significado, tipo y tratamiento de las 18 columnas. |
| Origen_Registros | 5500 | Procedencia y aportes CRM. Señala similitudes detectadas entre fuentes, sin afirmar identidad. |
| Control_Calidad | 5500 | Observaciones por registro, estado recibido y condiciones para cálculos de fechas. |
| Resumen_Calidad | 15 | Conteos de observaciones. Pueden superponerse y no deben sumarse como filas distintas. |
| Aspirantes_Origen | 3424 | Una fila por código de aspirante y sistema de origen. No es un total global confirmado de personas. |
| Coincidencias_Oracle | 500 | Comparación de registros Oracle con candidatos principales, con fechas e importes. |
| Control_Economico | 100 | Evidencia de matrícula base, derechos y total CRM, junto con el importe conservado o recuperado. |
| Registros_Sin_ID | 90 | Registros incluidos en la base que no tienen código de aspirante. No son filas adicionales. |
| Metodologia | 23 | Reglas aplicadas, decisiones cerradas, denominadores y límites de interpretación. |

El cruce entre fuentes ya se ejecutó. La similitud detectada es un resultado de ese control y no demuestra por sí sola identidad del evento. Las reglas de preparación están aplicadas. Persisten datos no confirmados y ausencias que se conservan explícitamente.
