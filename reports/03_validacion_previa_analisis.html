1. Cobertura y concentración de ausencias¶

Se cuenta cada columna vacía y se cruza con programa, modalidad, canal, estado, periodo y fuente. El porcentaje usa todos los registros de cada grupo. Sin información es una etiqueta de presentación, no un valor imputado. Las diferencias en puntos porcentuales son descriptivas. No prueban que las ausencias sean aleatorias o que exista una causa. La fecha de matrícula se interpreta por estado.

2. Comprobación de candidatos Oracle sobre los valores finales¶

Se reevalúan los 500 pares ya identificados, sin buscar equivalencias por código. La llave exploratoria exige correo, fecha de solicitud, programa, modalidad y periodo informados e iguales. Además se comprueban contradicciones entre los demás atributos informados, salvo los dos identificadores propios de cada sistema. Compartir un vacío no se cuenta como atributo informado coincidente. La compatibilidad de un par no demuestra que represente una sola solicitud.

keys = ['correo', 'fecha_solicitud', 'programa', 'modalidad', 'periodo_academico']
numeric = ['puntaje_admision', 'valor_matricula_cop', 'duracion_semestres']
comparable = [c for c in base.columns if c not in ['registro_id', 'aspirante_id']]
def equivalent(a, b, column):
    return Decimal(a) == Decimal(b) if column in numeric else a == b

checks = []

def markdown_table(frame):
    rows = [list(frame.columns), *frame.astype(str).values.tolist()]
    lines = ['| ' + ' | '.join(rows[0]) + ' |', '| ' + ' | '.join([':---'] * len(rows[0])) + ' |']
    lines += ['| ' + ' | '.join(r) + ' |' for r in rows[1:]]
    return '\n'.join(lines)
